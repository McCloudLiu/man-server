# Man Server

## 开发环境

### 开发环境及版本号

- node >= 18.x
- npm >= 8.x
- pnpm = 9.x
- typescript >= 5.x

### 安装教程

- Node/Npm 安装教程：[https://www.runoob.com/nodejs/nodejs-install-setup.html](https://www.runoob.com/nodejs/nodejs-install-setup.html)
- pnpm 安装教程：[https://www.pnpm.cn/installation](https://www.pnpm.cn/installation)

## 开发运行

### 1. 安装依赖

```bash
pnpm i
```

### 2. 本地运行

```bash
pnpm dev
open http://localhost:7001/
```

### 3. 部署服务

```bash
pnpm tsc
pnpm start
```
